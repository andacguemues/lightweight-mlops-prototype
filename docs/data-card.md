# Data Card: UCI Bank Marketing Dataset

## Dataset

UCI Bank Marketing Dataset

## Source

The dataset is provided by the UCI Machine Learning Repository.

## Citation

Moro, S., Rita, P., & Cortez, P. (2014). Bank Marketing [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5K306.

## License

## Task

Binary classification.

The goal is to predict whether a client subscribes to a term deposit.

Target variable:

- `y`: `yes` / `no`

## Selected File

`bank-additional-full.csv`

## Reason for Selection

The dataset is tabular, publicly available, small enough for local development and suitable for demonstrating a full MLOps lifecycle including data preparation, model training, evaluation, deployment and drift monitoring.

## Initial Notes

The dataset uses semicolon-separated values and contains categorical and numerical features.
